**[design-system-drift-lab](https://github.com/omkarpkh/design-system-drift-lab)**
A controlled reproduction: does documentation completeness or phrasing determine
whether AI-generated UI stays on-system? Three conditions, nine isolated runs,
74 graded properties — and one failed hypothesis, mine. Naming a value moved
accuracy from 93.2% to 100%; rephrasing the same rule changed nothing at all.

**[bulk-edit-mixed](https://github.com/omkarpkh/bulk-edit-mixed)**
The state model behind a bulk-edit interface, for when the selected items don't
agree with each other. Three outcomes not two, operations as a function of field
type, and diffs that stay reviewable at scale. 53 tests.
